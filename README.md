# Astro/physics Grad School Application CVs

A repository of CVs people included in their grad school applications.

I highly recommend reading this phenomenal AstroBites guide by Skylar Grayson, Brandon Pries, William Smith, 
Anavi Uppal, and Maria Vincent: https://astrobites.org/2025/09/23/guide_to_cvs/.

UC Boulder's Astrophysical & Planetary Sciences department also has a guide to CVs: https://www.colorado.edu/aps/undergraduate-studies/professional-development/applying-grad-school/curriculum-vitae.
